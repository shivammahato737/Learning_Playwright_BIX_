# Learning_Playwright_BIX_

Small collection of JavaScript operator examples used for learning and testing.

Project structure
- `addition.js` — sample addition examples
- `comparision.js` — comparison operator examples
- `operator/Increment_Decrement.js` — increment/decrement examples

Usage
- Run any file with Node.js:

```bash
node addition.js
node comparision.js
node operator/Increment_Decrement.js
```

No dependencies required.
